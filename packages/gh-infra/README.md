# gh-infra package

Builds the [gh-infra](https://github.com/babarot/gh-infra) GitHub CLI extension from source, starting from a derivation generated by `nix-init`. Once nixpkgs ships it, delete this directory and use `pkgs.gh-infra`.

## Updating the version

```sh
just update-gh-infra
```

This runs `nix-update` on the `gh-infra` flake package, which rewrites `version`, `hash`, and `vendorHash` in `package.nix` to the latest stable GitHub release, then formats and runs `nix flake check`.
