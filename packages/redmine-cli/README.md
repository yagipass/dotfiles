# redmine-cli package

Builds [redmine-cli](https://github.com/aarondpn/redmine-cli) from source, starting from a derivation generated by `nix-init`. The `redmine` wrapper sets `REDMINE_NO_UPDATE_CHECK=1` because Nix manages its updates. Once nixpkgs ships it, delete this directory and use `pkgs.redmine-cli`.

## Updating the version

```sh
just update-redmine-cli
```

This runs `nix-update` on the `redmine-cli` flake package, which rewrites `version`, `hash`, and `vendorHash` in `package.nix` to the latest stable GitHub release, then formats and runs `nix flake check`.
