# zabrze package

Builds [zabrze](https://github.com/Ryooooooga/zabrze) from source, starting from a derivation generated by `nix-init`. Once nixpkgs ships it, delete this directory and use `pkgs.zabrze`.

## Updating the version

```sh
just update-zabrze
```

This runs `nix-update` on the `zabrze` flake package, which rewrites `version`, `hash`, and `cargoHash` in `package.nix` to the latest stable GitHub release, then formats and runs `nix flake check`.
